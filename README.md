# Drone OPEN HOUSE 🚁

โปรเจกต์นี้เป็นระบบควบคุมการบิน (Flight Controller) สำหรับโดรนที่พัฒนาขึ้นเองโดยใช้ไมโครคอนโทรลเลอร์ **ESP32** ร่วมกับเซ็นเซอร์วัดความเฉื่อย (IMU) **MPU6050** โดยเน้นการพัฒนาโหมดการบินแบบ Angle Mode (รักษาสมดุลอัตโนมัติ) โครงสร้างโค้ดถูกแบ่งออกเป็นส่วนหลักสำหรับควบคุมการบิน การจูนพารามิเตอร์ และส่วนสำหรับทดสอบระบบฮาร์ดแวร์ต่างๆ

## 📂 โครงสร้างโฟลเดอร์และไฟล์ (Repository Structure)

โปรเจกต์นี้ประกอบด้วย 2 โฟลเดอร์หลัก:

### 1. `src/` (โค้ดหลักและการตั้งค่าการบิน)
*   [`main.cpp`](src/main.cpp)
    *   **โค้ดสำหรับการจูน PID (PID Tuning):** ใช้สำหรับปรับแต่งและหาค่าพารามิเตอร์ Proportional (P), Integral (I), และ Derivative (D) ที่เหมาะสมที่สุด เพื่อให้โดรนมีการตอบสนองที่เสถียร บินนิ่ง และควบคุมได้อย่างแม่นยำ
*   [`Anglemode_flightcontroller_ver3.1.ino`](src/Anglemode_flightcontroller_ver3.1.ino)
    *   **โค้ดหลักของโปรเจกต์ (Main Flight Controller):** ระบบควบคุมการบินเวอร์ชัน 3.1 ที่มาพร้อมฟังก์ชัน Angle Mode ช่วยรักษาระดับการบินให้ขนานกับพื้นโลกอัตโนมัติโดยอาศัยข้อมูลจาก Gyroscope และ Accelerometer รวมกับการคำนวณ PID Control
*   [`Gyro_accelerometer_calibration.ino`](src/Gyro_accelerometer_calibration.ino)
    *   **โค้ดสำหรับคาลิเบรทเซ็นเซอร์:** ใช้สำหรับหาค่าความคลาดเคลื่อน (Offset) ของเซ็นเซอร์ MPU6050 ในสภาวะหยุดนิ่ง เพื่อนำค่าที่ได้ไปใส่ในโค้ดหลัก ช่วยให้เซ็นเซอร์อ่านค่าได้แม่นยำที่สุด

### 2. `test/` (โค้ดสำหรับทดสอบและตั้งค่าฮาร์ดแวร์)
*   [`testjoy.ino`](test/testjoy.ino)
    *   **โค้ดทดสอบรีซีฟเวอร์ (Radio Receiver):** ใช้สำหรับเช็คสัญญาณและตรวจสอบค่าที่อ่านได้จากรีโมทคอนโทรลในแต่ละช่องสัญญาณ (CH1 - CH6) ว่าทำงานถูกต้องและมีการแมปปิ้ง (Mapping) ค่าที่เหมาะสมหรือไม่
*   [`motor_calibration_esp32_with_esc_calibration.ino`](test/motor_calibration_esp32_with_esc_calibration.ino)
    *   **โค้ดคาลิเบรท ESC (Electronic Speed Controller):** สำคัญมากสำหรับการเริ่มต้นระบบ ใช้เพื่อเซ็ตระยะคันเร่ง (Throttle Range) สูงสุดและต่ำสุดให้กับ ESC ทุกตัว เพื่อให้มอเตอร์ทุกตัวเริ่มหมุนพร้อมกันและให้กำลังขับที่เท่ากัน
*   [`test_motor_1234.ino`](test/test_motor_1234.ino)
    *   **โค้ดทดสอบการหมุนของมอเตอร์:** ใช้สำหรับตรวจสอบทิศทางการหมุนของมอเตอร์ทั้ง 4 ตัว (M1, M2, M3, M4) ว่าหมุนถูกต้องตามโครงสร้างเฟรม (เช่น หมุนทวนเข็ม/ตามเข็มนาฬิกา ในรูปแบบ Quad X) หรือไม่

## 🛠️ ขั้นตอนการเซ็ตอัพระบบ (Setup & Getting Started)

เพื่อความปลอดภัยและป้องกันความผิดพลาดของฮาร์ดแวร์ แนะนำให้ทำตามขั้นตอนดังนี้ **(ถอดใบพัดออกทุกครั้งในขั้นตอนที่ 1-4)**

1.  **ทดสอบสัญญาณรีโมท:** อัปโหลด `testjoy.ino` ตรวจสอบผ่าน Serial Monitor ว่าขยับสติ๊กบนรีโมทแล้วค่าที่ได้ตอบสนองถูกต้องตามแกน Throttle, Roll, Pitch, Yaw
2.  **คาลิเบรท ESC:** อัปโหลด `motor_calibration_esp32_with_esc_calibration.ino` ทำตามขั้นตอนการคาลิเบรท ESC (ดันคันเร่งสุด -> จ่ายไฟให้ ESC -> ฟังเสียงบี๊บ -> ดึงคันเร่งลงสุด) 
3.  **ทดสอบมอเตอร์:** อัปโหลด `test_motor_1234.ino` เช็คให้แน่ใจว่ามอเตอร์ 1-4 หมุนถูกตำแหน่งและถูกทิศทาง (CW / CCW) ตามแผนผัง Wiring
4.  **คาลิเบรท IMU:** วางโดรนบนพื้นราบที่ได้ระดับ อัปโหลด `Gyro_accelerometer_calibration.ino` รอจนกว่าจะได้ค่า Offset จากนั้นจดค่าที่ได้ไว้
5.  **จูน PID (ถ้าจำเป็น):** หากโดรนยังมีอาการสั่นหรือตอบสนองช้า สามารถใช้โค้ด `main.cpp` เพื่อทำการปรับจูนค่า PID ให้เหมาะสมกับน้ำหนักและโครงสร้างของเฟรม
6.  **อัปโหลดโค้ดหลัก:** นำค่า Offset ที่ได้จากข้อ 4 และค่า PID ที่จูนแล้ว ไปอัปเดตในไฟล์ `Anglemode_flightcontroller_ver3.1.ino` จากนั้นอัปโหลดโค้ดเข้าสู่ ESP32 ประกอบใบพัด และพร้อมสำหรับการทดสอบบิน

## ⚙️ ฮาร์ดแวร์ที่รองรับ (Hardware Requirements)
*   **Microcontroller:** ESP32-WROOM Module
*   **IMU Sensor:** MPU6050 (Gyroscope + Accelerometer)
*   **ESC & Motors:** Brushless Motors (ระบบ 4 แกน)
*   **Radio Receiver:** รองรับสัญญาณ PWM (6 Channels)
*   **Power:** แบตเตอรี่ LiPo (เช่น 3S หรือ 4S ตามสเปคของมอเตอร์)
